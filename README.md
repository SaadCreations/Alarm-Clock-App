# Alarm-Clock-App

A simple and elegant Alarm Clock application that allows users to set multiple alarms with hour, minute, and second inputs. The app displays the current time in real-time and plays an alarm sound when an alarm time is reached.

## Features:
- **Real-time clock:** Displays current time and updates every second.
- **Set multiple alarms:** Users can input the time for multiple alarms and view them in a list.
- **Delete alarms:** Users can delete any alarm they no longer need.
- **Alarm sound:** When the alarm time matches the current time, the app triggers an alarm sound.
- **Responsive design:** Looks great on both desktop and mobile devices.

## Installation:
1. Clone or download the repository.
2. Open `index.html` in your web browser.

## Usage:
1. Set the desired alarm time by entering hours, minutes, and seconds.
2. Click the "Set Alarm" button to add the alarm.
3. The current time will continuously update.
4. When an alarm's time matches the current time, the alarm sound will play.
5. You can delete alarms from the list by clicking the "Delete" button next to the alarm.
